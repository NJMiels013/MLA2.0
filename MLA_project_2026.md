# MLA - Final project 2026

### Description
In this project, you will design and implement machine learning (ML) models for a problem in the field of retail, namely to recognize (types of) clothing from images. For this, we use the “Fashion-MNIST” dataset: a description of the data and on how to import them in Python can be found here: https://github.com/zalandoresearch/fashion-mnist?t. The features are the pixels of the image and the labels are types of clothing.
The project consists of two parts:

#### Part 1. Basis approach using decision trees
- a. [5 pts] Implement a basic approach to the classification problem using decision trees. Analyze the results obtained from this model.
- b. [5 pts] Based on your findings, propose and implement a tree ensemble method to improve upon the decision tree model. Motivate your choice compared to other tree ensemble methods. Discuss both the expected and observed effects of using the ensemble method compared to the decision tree.

#### Part 2. More advanced approach
- c. [2 pts] Describe the shortcomings of the tree-based approach that you observed in part 1b.
- d. [4 pts] Use these shortcomings to motivate and propose a design of a suitable deep learning method.
- e. [4 pts] Explain how to implement your design and the type of results you expect to obtain from this method.

There are three deliverables:

The report should include a clear analysis of the data, how this motivates certain design choices, implementation, and discussion of the results. For each chosen methodology, you should present the details about implementation, and you should evaluate them using clear and appropriate performance measures. Moreover, clearly indicate any difficulties you have had, and how you resolved those difficulties.

You must copy the technology statement that is in the document “Rules on the use of AI” (see Canvas) and replace the text in capital letters with the requested information.
